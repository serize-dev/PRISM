# P.R.I.S.M.

A biomarker intelligence dashboard. It computes Bayesian diagnostic probability with ROC curves, pulls live data from PubMed, ClinicalTrials.gov, UniProt and KEGG, and runs R in the browser through WebR.

## Run it

Open <https://serize-dev.github.io/PRISM/>, or download `index.html` and open it in a browser. It calls live public APIs and loads its libraries from a CDN, so it needs an internet connection.

**Demonstration software.** Not a medical device and not for clinical use. It does not replace clinical judgment.
